# Legend row at 375 px: button "Legend" opens the switches

## Request
Open point of `2026-11-01-unified-chart-page.md`: in Setup mode the legend row (row 2 of `ChartTopBar`) scrolled sideways at 375 px. The owner delegated the design choice on 2026-11-04 ("Kendi önerini uygula"), and checks it the next day.

## Design (Artifact, 3 variants)
Artifact: https://claude.ai/artifact/N9nC2YzimtEYtNmxN6kni8
- A: wrap to 3 or 4 lines. No scroll, but about 100 px of chart height lost.
- **B: one button "Legend" that opens the switches below it. Chosen.** Closed: one line of about 30 px. All switches, tooltips and test IDs stay.
- C: symbols only. Rejected: no hover on a phone, and colour alone carries the meaning.

## Solution
Only below 30 rem container width (the phone rule). `ChartTopBar` shows the button `chart-legend-toggle` (`aria-expanded`) and hides `extra` until it is open. Open, the switches wrap (`flex-wrap`, no horizontal scroll). From 30 rem the row is the same as before. New keys `analysis.chart.key.toggle` and `.hint` (tr/en/de).

| File | Change |
|---|---|
| `components/chart-page/ChartTopBar.tsx` | Button, open state, wrap rule for `extra`. |
| `components/chart/ZoneChartPanel.tsx` | `chart-key` wraps on the phone. |
| `i18n/messages/analysis.ts`, `hints.ts` | Label and hint. |
| `e2e/mocked/chart-header.spec.ts` | 2 tests (375 x 812 open/close without side scroll, 1440 x 900 unchanged). Red first. |

## Cause
The legend row used `overflow-x-auto` and `whitespace-nowrap`. Seven switches are wider than 375 px, so the row scrolled sideways.

## Verification
- New tests in `chart-header.spec.ts` were red first (button not found), then green.
- Run: `chart-header`, `chart-page`, `chart-topbar`, `chart-layers-menu`, `analysis-chart`, `analysis-trades` — all passed. `tsc` and `eslint` have no output.
- Screenshots at 375 x 812 (closed, open) and 1440 x 900 checked.

## Lessons
- A part hidden by a container query breaks other specs that look for it. `chart-page.spec.ts` (UI-10) now opens the legend first below 480 px.
- With `short:` (landscape grid) and a container below 30 rem together, the legend wrapper needs its own grid row (`short:@max-[30rem]:col-span-3`). Do not add `col-span-3` for wider containers: the bar then grows above 66 px.
