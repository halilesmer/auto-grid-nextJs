# Market closed 10018 no longer locks zone

## Request
Fix defect D2 from `2026-10-28-backtest-live-comparison-result.md`. At the session start, MT5 rejects orders with retcode 10018 "Market closed". After 3 rejects the bot paused the zone until a restart.

## Cause
`send_pending_order_helper` in `grid_orders.py` counted every failed send in `consecutive_errors`. At 3, it called `pause_zone_for_safety` (ENG-11). A 10018 reject is not an order error. The loop check `is_market_open` did not stop this: it skips the tick only when all symbols are closed, and at the session start the last tick is often less than 180 s old.

## Solution
| File | Change |
|---|---|
| `worker_python/src/utils/trade_utils.py` | `safe_send_order` keeps the retcode of the last reject in `TradeState.last_retcode`. |
| `worker_python/src/core/state.py` | New `market_closed_until` per symbol. |
| `worker_python/src/core/grid_orders.py` | On 10018: do not count the error, log a warning, send no order for this symbol for `MARKET_CLOSED_CHECK_INTERVAL` (60 s), then try again. |

## Why
The wait is per symbol, because sessions differ per symbol. Other retcodes keep the ENG-11 lock.

## Verification
- New tests `ENG-32` in `tests/unit/test_eng_grid_tick.py`: red before the fix (zone paused, 6 order checks), green after.
- `pytest tests` → 897 passed.
